NORTH BEND

Juego detectivesco en 3D hecho con Three.js. Un detective recorre la escena de un accidente bajo la lluvia, examina las evidencias y emite un veredicto.

🎮 Jugar ahora

👉 https://northbend.netlify.app

El sitio se actualiza automáticamente con cada cambio subido a este repositorio.

Sobre el proyecto
Motor: Three.js (3D en el navegador)
Caso actual: #050 — accidente en carretera de bosque, 5 evidencias
Estado: prototipo en desarrollo
Cómo se trabaja
Se edita el index.html
Se sube a GitHub (rama main)
Netlify publica los cambios solo en ~1 minuto
